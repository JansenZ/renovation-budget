# 装修预算看板设计规格

## 目标

将用户提供的装修清单整理为一个可公开分享、适合手机和电脑阅读的单页预算看板。页面标题为“嘉宝花园装修清单”，记录 165㎡四室两厅两卫、约 52㎡窗体面积、260 万元购入总价，以及房龄、总楼层、梯户、电梯、容积率和学校信息。购房款只用于背景和单价参考，不计入装修预算。页面需要同时回答：总共花多少钱、每平方米成本、钱花在哪、硬装与软装各占多少、哪些支出本可纳入装修公司合同但实际在合同外承担，以及哪些项目可以入住后再购买。

页面最终部署在 GitHub Pages，计划使用 `home.zhenglin.vip`，不影响现有的 `zhenglin.vip` 知识库。

## 数据口径

- 金额统一使用人民币元，页面展示时使用中文千分位。
- 除“入住后双十一再买”外，其余项目默认记为“已购或已确定支出”。
- “入住后双十一再买”以及用户明确指出尚未购买的 6 项家具软装记为“待购”，纳入完整预算，但不计入当前已确定投入。
- 待购状态可以跨采购分组；家具待购项仍保留在“家具与软装”中并显示标签。
- 备注中明确列出的安装费、铜管费、面板延长费、燃气阀门费等计入对应项目的实际总价，并保留费用构成。
- “未知项备用”保留为待使用预算，不伪装成已经发生的消费。
- 原清单文字仅做明显错别字和单位规范化，不改变品牌、型号或配置含义。

## 分类模型

页面保留原始采购分组，同时增加两个分析维度。

### 采购分组

1. 门窗类
2. 装修公司及基础施工
3. 自购装修材料与主材
4. 智能家居
5. 家电
6. 家具与软装
7. 入住后待购

### 空间属性

- 硬装：固定在房屋上、拆除或更换会影响装修面的项目。
- 软装：家具、窗帘、地毯、装饰及可移动生活用品。
- 家电与智能：可独立更换的电器、网络和智能设备。
- 待购：入住后购买的独立预算。

### 装修责任

- 装修公司合同内：19 万元硬装合同主体。
- 合同外但本可纳入装修公司范围：门窗、装修公司增项、固定柜体、基础辅材、开关配电、灯具、卫浴、固定水电配件等。
- 业主独立采购：家电、智能设备、可移动家具和生活用品。

“本可纳入”表示完整整装合同中可以约定由装修公司供应或负责，并不表示所有装修公司都默认包含。

## 页面结构（2026-08-20 精简版）

### 页首

- 小尺寸标题“家的装修清单”与更新日期。
- 完整预算、当前投入、硬装投入和入住后待购四个核心数字。

### 预算构成与装修观察

- 用四条紧凑进度条展示硬装、软装、家电智能与待购金额及比例。
- 基于清单本身给出合同覆盖、门窗投入、家具家电结构和延后采购四条装修观察。
- 不生成行业评分或未经提供的市场均价。

### 分类明细

- 清单是页面主体；每个分类显示小计、占比和项目数。
- 可展开查看项目、基础价格、附加费用、合计和备注。
- 所有分类默认折叠，避免页面第一次打开过长。

### 口径说明

- 解释硬装、软装、合同外项目和已确定/待购口径。
- 标注页面为个人预算记录，品牌和价格不构成购买建议。

## 视觉设计

- 风格为简单、温暖、紧凑的家庭账本，而不是展示型财务看板。
- 使用米白背景、深墨文字、陶土橙与鼠尾草绿作为主要强调色。
- 使用高对比、适中字号和紧凑留白。
- 图表使用原生 SVG/CSS 绘制，不依赖外部图表服务。
- 页面在 360px 手机、常见平板和桌面宽度下均可阅读。
- 遵循键盘操作、可见焦点和减少动态效果等无障碍要求。

## 技术结构

- 纯静态 HTML、CSS 和 JavaScript，无构建步骤、无数据库。
- 清单数据集中保存在单独的 `data.js`，页面根据数据实时计算所有小计和占比，避免手写汇总不一致。
- `index.html` 负责语义结构，`styles.css` 负责响应式视觉，`app.js` 负责计算、渲染和折叠交互。
- 后续若增加编辑接口，只需将 `data.js` 替换为 API 读取层，不改变页面分类模型。

## 部署方案

- 新建公开 GitHub 仓库 `jansenz/renovation-budget`。
- 从默认分支根目录发布 GitHub Pages。
- Pages 自定义域名设置为 `home.zhenglin.vip`。
- 阿里云 DNS 添加 `home` 的 CNAME，目标为 `jansenz.github.io`。
- DNS 生效后在 GitHub Pages 开启 Enforce HTTPS；证书由 GitHub 自动签发和续期。

## 校验标准

- 所有原始项目均进入页面且无重复、无遗漏。
- 每个分组小计等于项目金额之和，完整预算等于所有分组之和。
- 附加费用正确计入，且用户能看见其构成。
- 责任口径与空间属性口径的总额均能回算到同一个完整预算。
- 页面在 360px 和 1440px 宽度下无横向溢出或文字遮挡。
- JavaScript 无控制台错误，折叠交互支持鼠标和键盘。
- GitHub Pages 与自定义域名均能通过 HTTPS 访问。

## 明确不做

- 第一版不提供登录、在线编辑、多人协作、数据库或票据上传。
- 不购买 ECS、OSS、付费证书或 CDN。
- 不修改现有 `zhenglin.vip` 知识库仓库和根域名页面。
