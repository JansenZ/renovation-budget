# 嘉宝花园装修清单

一个无依赖的静态房屋档案与装修账本，记录嘉宝花园 165㎡四室两厅两卫的购房背景，以及 113 项硬装、软装、家电智能与待购支出。页面以 `#home`、`#budget` 和 `#decision` 三个地址分别分享房屋资料、装修记录与购房选择过程。

## 购房选择记录

这 7 套候选是看过大量房源、经过硬门槛、实地看房和家庭决策三轮筛选后留下的：和茂苑一期、瀚河苑、颐和湾花园、阳光水榭三期、阳光水榭五期、嘉宝花园 9 楼与嘉宝花园 11 楼。终选聚焦水榭三期 1 楼和嘉宝 11 楼，最终以 260 万元购买嘉宝花园 11 楼；水榭卖方从 295 万元改报 315 万元后退出。

页面同时保留两套口径：

- 可复用的 100 分模型：先对交通、户型、使用面积、全周期成本等 10 个维度打 0–10 分，再乘以总和为 100% 的个人偏好权重。
- 购房时的原始模型：各基础项直接相加，总价分为`（450 万元－房价或全周期成本）÷10 万元`，再加上花园、车库、噪声或得房率等特殊修正。

候选卡按原始得分降序排列，展示全部 10 个分项、回算公式与未选择原因。家属不接受、超预算、无法治理的重大缺陷与产权／学区无法核实被单独作为否决项，不与普通分数相互抵消。

候选房评分来自购房时的个人模型，只用于还原当时的决策过程。学校对应关系参考苏州市教育局 2023–2026 年公开施教区资料，实际入学仍需按当年政策、分期和产权门牌复核。详细核验记录见 `docs/research/school-districts.md`。

所有汇总均由 `assets/data.js` 经 `assets/budget.js` 实时计算，页面中没有手写汇总数值。

## GitHub Pages

仓库目标为 `jansenz/renovation-budget`，从 `main` 分支根目录发布。

自定义域名：

```text
home.zhenglin.vip
```

阿里云 DNS 记录：

| 字段 | 值 |
|---|---|
| 记录类型 | CNAME |
| 主机记录 | home |
| 记录值 | jansenz.github.io |
| TTL | 默认 |

DNS 生效、GitHub 签发证书后，在仓库的 Pages 设置中开启 **Enforce HTTPS**。不要修改根域名 `zhenglin.vip` 当前用于知识库的解析记录。

## 未来接口

第一版不包含后端。若以后需要在线编辑，将 `assets/data.js` 替换为一个返回相同 `ExpenseGroup[]` 结构的 API 数据源即可；预算计算、分类模型和页面渲染无需重写。前端可以继续留在 GitHub Pages，API 单独部署到函数计算或轻量服务器。
